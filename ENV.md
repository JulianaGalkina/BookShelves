### Инструкция по подключению базы данных Supabase

1. Создайте аккаунт на https://supabase.com и новый проект.
2. В корневой папке BookShelves создайте файл `.env.local`, скопировав содержимое `.env.example`.
3. В настройках проекта Supabase перейдите в раздел **Project Settings → API**.
4. Скопируйте адрес проекта (Project URL) и публичный ключ (anon key).
5. Вставьте полученные значения в соответствующие переменные файла `.env.local`:
   - `VITE_SUPABASE_URL` — адрес проекта Supabase.
   - `VITE_SUPABASE_ANON_KEY` — публичный ключ API.
6. Выполните настройку базы данных согласно инструкции `supabase/README.md`.
7. Сохраните файл, установите зависимости командой `npm install` и запустите проект командой `npm run dev`.

**Важно:** файл `.env.local` предназначен для локального использования и не должен загружаться на GitHub. Файл `.env.example` остаётся публичным шаблоном с пустыми значениями.
