# 📚 Shelves

## О проекте

BookShelves — веб-приложение для создания личной книжной библиотеки и ведения читательского дневника. Оно позволяет организовывать книги по полкам, отслеживать процесс чтения, выставлять оценки и сохранять личные впечатления.

Проект разработан в рамках обучения Vibe Coding с использованием искусственного интеллекта.

**Технологии:** React, JavaScript, Vite, Supabase.

## Структура проекта

- `PRD.md` — описание продукта и функциональные требования.
- `DESIGN.md` — дизайн и визуальная концепция приложения.
- `ARCHITECTURE.md` — техническая архитектура проекта.
- `PLAN.md` — план и этапы разработки.
- `AGENTS.md` — инструкции для ИИ-агентов.
- `src/` — исходный код приложения.
- `supabase/` — файлы базы данных и инструкция по её настройке.
- `package.json` — зависимости и команды запуска проекта.
- `.gitignore` — список исключаемых файлов.

## Подключение базы данных

В проекте используется внешняя база данных Supabase. Для подключения необходимо создать файл `.env.local` и заполнить переменные окружения на основе шаблона `.env.example`.

Подробная инструкция по настройке находится в [supabase/README.md](supabase/README.md).
