# План реализации книжного дневника

Основан на согласованном [PRD.md](./PRD.md). План сохранён отдельно; предыдущие документы не перезаписывались.

## Объём первой версии

1. Один экран общего списка книг с фильтром по статусу.
2. Добавление и редактирование книги: название, автор, статус, впечатление; поля оценки и дат показываются согласно статусу.
3. Статусы: «читаю», «в планах», «прочитано», «отложено». Для читаемой книги автоматически ставится дата начала; при завершении — текущая дата. Даты можно исправлять. Для планируемой книги нет дат и оценки; для отложенной даты нет.
4. Удаление записи и локальное сохранение в браузере.
5. Адаптивный интерфейс на React + Vite по [DESIGN.md](./DESIGN.md): тёплый фон, постоянная синяя обложка у каждой книги и сведения рядом с ней.

## Вне объёма

Аккаунты и синхронизация, общая база, социальные функции, рекомендации, каталог книг и другие будущие функции из PRD.

## Завершение

- Запустить локальный сервер разработки.
- Проверить вручную: создание/редактирование по статусам, фильтр и отображение списка, сохранение после перезагрузки.
- Отразить фактический статус и известные ограничения в PRD.

## Статус

Функции реализованы; во второй версии применён Pinterest-референс и добавлена одинаковая цветная обложка с информацией о книге рядом. Решение описано в DESIGN.md. Локальный сервер запущен. Автоматические тесты не добавлялись по PRD. Требуется ручная проверка пользователем.
