# PRD: Книжный трекер Shelves

**Статус:** основные функции первой версии реализованы. Интерфейс описан в [DESIGN.md](./DESIGN.md): упрощённая шапка с названием приложения и информацией об аккаунте, заголовок «Каталог» и отдельные карточки книг с тонкой рамкой и небольшим скруглением. Название и автора пользователь вводит вручную. План: [PLAN.md](./PLAN.md).

## Для кого и какую задачу решает

Shelves — базовый личный трекер для читателей, которые ведут список книг для себя, читают несколько книг параллельно и хотят помнить, что уже прочитали, что отложили и что планируют прочитать. Для каждой книги можно сохранять личные заметки и впечатления, чтобы зафиксировать собственное мнение и детали, к которым хочется вернуться.

## Основной пользовательский сценарий

Читатель вручную добавляет книгу, указывает название и автора, выбирает статус и при желании папку, а затем записывает личную заметку-впечатление. Позже он может изменить запись, оценить книгу, обновить даты, отфильтровать или отсортировать каталог.

Статусы книги: «читаю», «в планах», «прочитано» и «отложено». Оценка доступна для статусов «читаю», «прочитано» и «отложено»; у статуса «в планах» оценки и дат нет. Для статусов «читаю» и «прочитано» можно указать необязательную дату начала чтения. При переводе книги в статус «прочитано» автоматически устанавливается текущая дата завершения; её и оценку можно изменить.

## Экраны и интерфейс

В первой версии один экран «Каталог» с общим списком книг и действием «Добавить книгу». Формы добавления и редактирования открываются в модальном окне. Каждая книга показана в отдельной карточке.

Элементы интерфейса: блоки папок только с названием и количеством книг; ниже — название выбранной папки и действия переименования и удаления. Также доступны сортировка списка по названию, автору, дате прочтения, дате добавления или рейтингу, фильтр по статусу, карточки каталога с обложкой и сведениями о книге, статус, оценка (кроме статуса «в планах»), фрагмент впечатления, необязательная дата начала для статусов «читаю» и «прочитано», дата завершения для прочитанных книг, действия добавления, редактирования и удаления.

## Функции первой версии

1. **Каталог книг.** Добавление, редактирование и удаление записей. Для книги указываются название и автор, статус, папка, оценка, личное впечатление, даты начала и завершения чтения. Дата добавления создаётся автоматически.
2. **Учёт чтения.** Четыре статуса: «читаю», «в планах», «прочитано» и «отложено». Оценка доступна для читаемых, прочитанных и отложенных книг; у запланированных книг нет оценки и дат. Дата начала необязательна для читаемых и прочитанных книг. При статусе «прочитано» подставляется текущая дата завершения, которую можно изменить; у отложенных книг даты не показываются.
3. **Личные заметки и впечатления.** Пользователь может добавить и изменить текст о книге; заметка показывается в карточке каталога.
4. **Просмотр каталога.** Общий список книг с фильтром по статусу и папке. Карточка показывает обложку и сведения о книге.
5. **Сортировка.** Список сортируется по названию, автору, дате прочтения, дате добавления или рейтингу, по возрастанию и убыванию. Книги без значения выбранного поля остаются в конце.
6. **Папки.** Пользователь создаёт, переименовывает и удаляет папки, назначает книги папкам и фильтрует список по выбранной папке. Книга может находиться не более чем в одной папке; при удалении папки книги остаются в каталоге без папки.
7. **Обложки.** Для книги создаётся цветная обложка с названием. Пользователь может выбрать фотографию с устройства; при этом название на обложке скрывается.
8. **Локальное сохранение и экспорт.** Книги, папки и фотографии сохраняются в браузере. Библиографические данные и названия папок можно экспортировать в CSV; фотографии в CSV не включаются.

## Данные проекта и их источники

- Книги и их названия, авторов, статусы, оценки и личные заметки пользователь вносит вручную. Внешний книжный каталог или API в первой версии не используются.
- Даты начала чтения пользователь указывает сам; дата завершения автоматически ставится при выборе статуса «прочитано» и может быть изменена.
- Папки создаёт пользователь. Дата добавления новой книги фиксируется приложением автоматически.
- Цветная обложка создаётся приложением; фотографию для обложки пользователь выбирает на своём устройстве.
- Записи, папки и фотографии хранятся локально в браузере пользователя. Они не отправляются на сервер и не синхронизируются; очистка данных браузера может удалить их.

## Границы проекта

Shelves — базовый проект для небольшой аудитории и частного использования. Первая версия рассчитана на личный каталог одного пользователя в одном браузере и не предназначена для публичного книжного сервиса или массовой эксплуатации.

В первую версию не входят сервер и общая база данных, регистрация и авторизация, синхронизация между устройствами, импорт из внешних книжных каталогов, рекомендации, социальные функции и публичное распространение заметок. Эти возможности можно рассматривать как будущие доработки.

## Технические решения

- Демо-приложение на React + Vite.
- Адаптивный интерфейс следует [DESIGN.md](./DESIGN.md): у каждой записи отдельный вертикальный фрейм обложки с пропорциями 2:3, постоянный цвет выбирается из палитры; сведения о книге располагаются рядом.
- Без отдельного сервера и базы данных; пользовательские данные хранятся локально в браузере.
- Тесты на этом этапе не делаем.

## Проверки результата

1. Можно добавить книгу с названием и автором и выбрать любой из четырёх статусов; оценка доступна для статусов «читаю», «прочитано» и «отложено», но отсутствует для «в планах».
2. Дата начала чтения доступна и необязательна для статусов «читаю» и «прочитано»; при переводе книги в «прочитано» появляется текущая дата завершения, которую можно изменить. Оценку можно менять. Общий список и фильтр по статусу отображают правильные записи.
3. После перезапуска страницы записи остаются в том же браузере; редактирование и удаление отражаются в списке.
4. Без фотографии название видно белым текстом внизу слева на цветной обложке; выбранная фотография сохраняется после перезагрузки страницы и заменяет цветной фон, а текст на самой обложке скрывается.
5. Список сортируется по названию, автору, дате прочтения, дате добавления и рейтингу в обоих направлениях; записи без даты или оценки остаются в конце.
6. Можно создать папку, добавить в неё книгу, увидеть правильное количество книг в блоке, отфильтровать по папке и вернуть книгу в общий каталог без папки. Папки и назначения сохраняются после перезагрузки.
7. При создании папки можно выбрать существующие книги; папку можно переименовать и удалить, при удалении книги остаются без папки. Экспорт скачивает универсальный CSV с данными книг и названием папки, без фото обложек.
