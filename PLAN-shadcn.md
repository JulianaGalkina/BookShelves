# План применения shadcn/ui и целевого стиля Shelves

## Источники требований

- `PRD.md` — источник требований к функциям, пользовательским сценариям, русским текстам и данным.
- `DESIGN.md` — источник целевого визуального стиля, бренда Shelves, типографики, палитры, отступов и форм компонентов.
- `shadcn/ui` — выбранная библиотека компонентов; использовать её исходные компоненты, стилизованные в соответствии с `DESIGN.md`.

Если эти документы в будущем будут расходиться, сначала обсудить противоречие с пользователем и не менять соответствующую часть интерфейса до решения.

## Цель и границы

- Применить shadcn/ui в существующем приложении на React + Vite.
- Сохранить одностраничную компоновку и адаптивное поведение.
- Сохранить функции, сценарии, поля, русские тексты PRD и существующие данные `localStorage`.
- Использовать Shelves как бренд/словесный логотип; оставить заголовок экрана «Мои книги» и остальные русские тексты.
- Не добавлять функции, экраны или автоматические тесты.

## Целевой интерфейс

- Применить кремовый фон `#F6F3EB`, мягкие белые поверхности `#FFFEFA`, тёмный сине-серый текст `#253044` и постоянную синюю обложку `#18366C` для каждой книги.
- Использовать книжную антикву для крупных заголовков, названий книг и впечатлений; Inter оставить для элементов управления и метаданных.
- Сохранить общий ритм и размеры текущей компоновки, но привести кнопки, поля, статусы, заголовки и разделители к правилам `DESIGN.md`.
- Представить книги в адаптивной сетке; внутри каждой карточки расположить одинаковую вертикальную обложку слева и информацию о книге справа. На узком экране уменьшить обложку, сохраняя горизонтальную компоновку.
- Использовать тёмно-синий для обложки, главного действия и фокусного состояния; цвет обложки не должен заменять текстовую метку статуса.

## Компоненты для применения

| Элемент приложения | Компонент/подход |
| --- | --- |
| Основные и вторичные кнопки | shadcn/ui `Button` |
| Название и автор | `Input` |
| Впечатление | `Textarea` |
| Статус, оценка и фильтр | `Select` либо `Native Select`, если это лучше сохраняет текущее поведение |
| Подписи и группы полей | `Label` / `Field` |
| Добавление и редактирование | `Dialog` |
| Метка статуса | `Badge` с нейтральным оформлением и текстовой подписью |
| Разделители книжного списка | `Separator` или тонкая CSS-граница |
| Подтверждение удаления | При необходимости `Alert Dialog` с тем же текстом и теми же действиями подтверждения/отмены |

Даты оставить нативными `input type="date"`. Не добавлять чекбоксы: отдельной отметки выполнения в текущем сценарии нет. Не оформлять строки книг как отдельные тяжёлые `Card`-контейнеры.

## Зависимости и настройка

- Добавить Tailwind CSS и Vite-плагин Tailwind по актуальной официальной инструкции shadcn/ui.
- Инициализировать shadcn/ui и добавить только необходимые компоненты.
- Создать `components.json`, настроить импорт компонентов и тему с CSS-переменными из `DESIGN.md`.
- Подключить Inter. Выбрать способ поставки шрифта при реализации, не добавляя второй шрифт.
- Установить вспомогательные пакеты и основы компонентов, которые потребуются выбранным компонентам shadcn/ui; точный набор определить при настройке CLI.

## Этапы применения

1. Настроить Tailwind CSS и shadcn/ui для существующего Vite-проекта, не заменяя React/Vite и не меняя функциональный код.
2. Подключить шрифт Inter и перенести цветовые, типографические, интервальные и скруглённые токены из `DESIGN.md` в тему приложения.
3. Применить компоненты shadcn/ui по таблице выше, сохраняя текущие названия, подписи, порядок полей и расположение основных областей страницы.
4. Заменить существующее отображение бренда «книжный дневник» на Shelves; оставить экранный заголовок «Мои книги» и остальную русскую копию PRD.
5. Сохранить логику статусов, оценок и дат, добавление/редактирование/удаление, фильтр, пустое состояние, ключ `book-diary-v1` и текущий формат записей в `localStorage`.
6. Вручную сверить три сценария проверки из PRD: поля и статусы, даты/фильтрация, сохранение после перезагрузки. Автоматические тесты не добавлять согласно PRD.

## Критерий готовности

Интерфейс использует компоненты shadcn/ui в целевом стиле `DESIGN.md`; бренд отображается как Shelves; заголовок экрана и русские тексты PRD сохранены; все функции и данные продолжают работать по существующим сценариям.
